# BUG-04: Статистикийн нийт номын тоо жагсаалтын тооноос зөрдөг

Орчин: Уншлагын жагсаалт v2.0, Microsoft Edge 158.0.0.0, Windows, Node.js v24.19.0, 2026-11-24
Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан; эхний 3 ном жагсаалтад байна.

## Дахин гаргах алхам

1. Аппыг шинээр асаагаад `http://localhost:3000`-ийг нээнэ.
2. Номын жагсаалт дахь мөрийн тоог тоолно (`GET /api/books` мөн 3 ном буцаана).
3. `GET /api/stats`-ийн `total` утгыг шалгана.

Хүлээгдэж байсан: `total` нь жагсаалтын номын тоотой тэнцүү буюу `3` байна.

Бодит үр дүн: Жагсаалт 3 номтой боловч `/api/stats` `{"total":4,"newest":2008}` буцааж, UI “Нийт ном: 4” гэж харуулна.

Ноцтой байдал: Minor — жагсаалт өөрөө ашиглагдах боловч нийт тооны мэдээлэл буруу.

Хавсралт: `/api/books` болон `/api/stats`-ийн бүтэн `curl -i` гаралт `../evidence/bug-04-curl.txt`
