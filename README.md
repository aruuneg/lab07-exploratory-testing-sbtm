## Ажлын тойм

`charter.md`-д тестийн зорилго болон Supermodel, Saboteur аяллыг сессээс өмнө тодорхойлсон. Шинээр асаасан апп дээр хийсэн тусдаа black-box шалгалтаар дөрвөн зөрчлийг дахин гаргасан; дэлгэрэнгүй алхам, хүлээгдсэн/бодит үр дүн нь `bugs/` дотор бий. API-ийн `curl -i` бүтэн хариунууд `evidence/` дотор UTF-8 текстээр хадгалагдсан.

## Сессийн төлөв

Шаардлагатай тасралтгүй 60 минутын exploratory session хараахан хийгдээгүй. Хуучин тайланд байсан 14:00–15:00 цагийг хүчинтэй гэж үзэх боломжгүй: charter-ийн commit 2026-10-14 22:11:59 (+08:00)-д хийгдсэн бөгөөд тухайн сессийн түүхий цагтай тэмдэглэл байхгүй. `session-report.md`-д зөвхөн баталгаажуулалтын тэмдэглэл болон дутуу байгаа сессийн төлөвийг ил тод тэмдэглэсэн; энэ ажлыг эцэслэн илгээхийн өмнө 60 минутын сессийг хийж, жинхэнэ HH:MM тэмдэглэл болон цагийн задаргааг нэмнэ.

## Түр дүгнэлт

Одоогийн баталгаажуулалтаар Supermodel-ийн GUI шалгалт хоосон гарчигтай ном нэмэгддэг болон хайлт том/жижиг үсгийг ялгадаг зөрчлийг илрүүлэв. Эдгээр хоёр UI зөрчлийн скриншотыг `screenshots/` хавтаст хадгалсан. Saboteur-ийн API шалгалтаар буруу JSON-д `400` биш `200 OK` буцаж байгааг харуулав. Эхний өгөгдөлтэй `/api/books` гурван ном буцаасан ч `/api/stats` нийт дөрөв гэж мэдээлсэн. Хүчинтэй нэмэх, хайлт, тоолуурын дүрмийг Playwright-ийн тодорхой assertion-уудаар давтан шалгаж болох байсан. Буруу JSON-ийн статус болон нийт тооны зөрүүг API шалгалтаар автоматаар барих боломжтой. Жилийн UI формат болон товчны өнгө зэрэг харагдах байдлын шалгалтад тусгай assertion эсвэл хүний ажиглалт шаардлагатай. Эдгээр нь зөвхөн урьдчилсан баталгаажуулалтын үр дүн бөгөөд бүрэн 60 минутын сессийн дүгнэлт биш.
